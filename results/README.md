# Included validation evidence

This public package contains the selected closed evidence required by the
automated tests and Paper 1 baseline gate.

It does not contain every bulky production state-history file created during
the complete project. The manuscript figures, tables, summary values, closed
external-validation outputs, and evidence hashes are retained.

Do not edit or replace files inside the timestamped evidence directories if
exact baseline verification is required. New experiments should write to new
timestamped directories.
