# Paper materials

`manuscript/PAPER1_MANUSCRIPT_PREPRINT.pdf` is the current author preprint of:

**Reproducible Comparison and Validation of Low-Earth-Orbit Propagation
Models**

Status: complete author manuscript, not accepted and not published.

The intended journal is the AIAA Journal of Aerospace Information Systems.
The repository provides the author-created preprint, not a publisher-formatted
version. A final repository URL and archive DOI must be inserted only after
those identifiers are publicly accessible.

The `assets` directory contains the five manuscript figures in PNG and PDF
formats and the numerical tables used to trace the reported claims.
