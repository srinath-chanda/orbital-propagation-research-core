# Data

The directory contains fixed inputs needed to reproduce the registered
research cases and verify the closed external evidence.

- `tle`: frozen ISS TLE and retrieval metadata;
- `reference/gmat*`: prepared GMAT scripts, raw reports, and manifests;
- `reference/gmat_r2026a`: gravity, atmosphere, and Earth-orientation
  reference files used for deterministic validation; and
- `maps`: a visualization-only ground-track background.

See `THIRD_PARTY_NOTICES.md` before redistributing any external reference file.
Do not replace frozen inputs with current downloads when verifying the Paper 1
baseline.
