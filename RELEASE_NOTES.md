# Release notes

## Version 0.1.0

Initial public research release candidate for Paper 1.

Included:

- the frozen propagation and analysis source;
- registered Paper 1 configurations;
- automated scientific and evidence-integrity tests;
- selected closed GMAT validation evidence;
- publication figures and numerical tables;
- the current author manuscript preprint; and
- installation, reproducibility, scope, citation, and third-party notices.

Public-release cleanup:

- removed virtual environments, caches, temporary logs, old packaging
  attempts, and internal manuscript-generation utilities;
- normalized machine-specific paths in portable preparation metadata and GMAT
  scripts;
- replaced an untracked-provenance map texture with a neutral project-created
  visualization background;
- refreshed affected package manifests after path-only normalization; and
- assigned the public software version `0.1.0`.

Scientific configurations, raw GMAT outputs, numerical acceptance thresholds,
and published result values were not changed by the public-release cleanup.
