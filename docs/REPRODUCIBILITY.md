# Reproducibility guide

## 1. Verify the packaged release

```bash
python scripts/verify_release.py
```

This checks required repository files, disallowed build artifacts, private
machine paths, and every file registered in `MANIFEST.sha256`.

## 2. Run automated tests

```bash
python -m unittest discover -s tests -v
```

The suite includes physics checks, configuration checks, external-evidence
integrity checks, and Paper 1 baseline checks.

## 3. Verify the closed validation baseline

```bash
python scripts/verify_paper1_baseline.py
```

The baseline requires the recorded two-body, J2, Earth-orientation,
higher-order gravity, and simplified-drag validation evidence. It checks file
hashes before authorizing production.

No new GMAT run is required. Do not edit files in the closed evidence
directories if exact baseline verification is required.

## 4. Reproduce the Paper 1 matrix

Prepare registered run files:

```bash
python scripts/prepare_paper1_production.py
```

Run the matrix:

```bash
python scripts/run_paper1_production.py
```

The matrix contains:

- LEO400 at 6, 24, 72, and 168 h;
- SSO700 at 6, 24, 72, and 168 h; and
- ISS fixed-TLE comparison at 6, 24, and 72 h.

It records 43 primary model runs and 47 executions. Four additional SSO700
drag outputs are generated by the controlled runner and are not counted as
primary Paper 1 runs.

## 5. Consolidate new results

After an 11 of 11 production completion:

```bash
python scripts/run_paper1_results_consolidation.py
python scripts/verify_paper1_results_consolidation.py
```

The original manuscript figures and tables are already included under
`paper/assets`. A new production run will have different runtime values and a
different timestamped result directory even when the physical conclusions are
unchanged.

## Exact-input rules

- Use the registered JSON case files without changing model settings.
- Use the frozen ISS TLE for the Paper 1 comparison.
- Do not substitute a current IERS file when verifying the closed evidence.
- Record Python and package versions for every new production run.
- Treat fixed-TLE SGP4 as a model reference, not measured orbit truth.
